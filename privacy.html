Who uses Clio

Clio is used only by its owner, Alex Jukes. Only the owner's own Google account is connected to it.

Google data Clio accesses

  • Gmail: reads messages; applies labels and archives routine messages; creates drafts. Clio does not send email.
  • Google Calendar: reads events (read-only).
  • Google Drive: reads files (read-only).

How the data is used

The data is used only to provide features to the owner, such as daily briefings, inbox filing and draft replies. To produce these, Clio may send the relevant content to AI model providers, which process it and return a response. Google user data is never sold, used for advertising, or shared with anyone else.

Storage and security

OAuth tokens and Clio's working notes are stored on a private, encrypted server controlled by the owner, hosted on Amazon Web Services in the EU (Stockholm). The server accepts no inbound connections from the internet.

Retention and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Once access is revoked, the stored tokens stop working and are deleted. To request deletion of any other stored data, contact the address below.
